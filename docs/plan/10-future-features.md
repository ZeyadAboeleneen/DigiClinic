# 10 — Future Features (مرتبة بالأولوية المقترحة)

1. **متابعة العروض:** تذكير للـsales بعد X أيام من الإرسال من غير رد، وقبل انتهاء الصلاحية.
2. **قوائم أسعار للعملاء:** سعر ثابت متفق عليه لعميل معين يتملى تلقائيًا.
3. **تحويل العرض لأمر توريد → إذن تسليم → فاتورة** بنفس الهوية (الـGuideline ذاكرهم أصلًا).
4. **رابط عرض للعميل:** صفحة يشوف فيها العرض ويضغط "موافقة" (مع تتبع الفتح).
5. **تقارير:** أكتر المنتجات طلبًا، معدل القبول لكل عميل وكل sales، قيمة العروض الشهرية.
6. **سعر التكلفة وهامش الربح** لكل صنف وكل عرض.
7. **2FA** للأدمن.
8. **استقبال ردود WhatsApp** في النظام (العميل يرد على العرض → يظهر تحت العرض).
9. **الانتقال لـWhatsApp Cloud API الرسمي** لو الحجم زاد أو ظهرت مشاكل حظر.
10. **Multi-tenant onboarding:** شاشة تسجيل شركة جديدة، اشتراكات، حدود استخدام.
11. **تطبيق موبايل / PWA** لو الاستخدام من الموبايل كتير.
12. **المناقصات الحكومية:** قوالب خاصة وكراسات شروط (لو المجال الكهربائي/الصناعي داخل).
