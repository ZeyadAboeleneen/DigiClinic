# DigiClinic — نظام إدارة العيادات
### Digitiva · Execution-Ready Plan · v1.0 · أكتوبر 2026

نظام لإدارة العيادة: حجز المواعيد مع تذكيرات تلقائية على الواتساب والإيميل، وشاشة استقبال، وشاشة للدكتور
فيها ملف المريض، وروشتة بتتكتب أو تتملي بالصوت وتتطبع PDF وتتبعت للمريض.
**مبني على كود مرسول البرق** (نفس الـstack ونفس الـmulti-tenancy ونفس بوابة الواتساب)، والهدف من الأول إنه يتباع
لعيادات كتير (SaaS).

## القرارات النهائية (Locked)

| البند | القرار |
|---|---|
| الأساس | Fork من مرسول البرق: `core`, `accounts`, `organizations`, `audit`, `messaging`, `documents` بيتنقلوا. `quotations` و`catalog` بيتشالوا |
| Backend + UI | Django 5.2 LTS + HTMX 2 + Alpine.js 3، عربي RTL |
| Database | PostgreSQL 16 (مدمج local عن طريق `pgserver`) |
| Background | **عملية واحدة `run_scheduler`** (local وعلى السيرفر). Celery/Redis **مش مطلوبين** في النسخة الأولى |
| PDF | Chromium عن طريق Playwright (زي البرق) |
| WhatsApp | بوابة `whatsapp-gateway/` (whatsapp-web.js) زي البرق، والـprovider قابل للتبديل لـWhatsApp Cloud API بعدين |
| Email | SMTP من الإعدادات (زي البرق) |
| Multi-tenancy | كل عيادة = `Organization`. كل جدول عليه `organization_id` |
| حجم النسخة الأولى | **دكتور واحد في الواجهة**، لكن كل الجداول فيها `doctor` من الأول (التوسع لأكتر من دكتور مش محتاج migration صعبة) |
| طريقة الحجز | **الاتنين حسب الإعدادات** لكل دكتور: `slots` (ميعاد بالدقيقة) أو `queue` (رقم دور + ميعاد تقريبي) |
| التذكيرات | تأكيد فوري + قبلها بـ24 ساعة + قبلها بساعة (التوقيتات والنصوص والقنوات بتتعدل، وينفع تتضاف تذكيرات) + رسالة عند التعديل والإلغاء + "دورك قرّب" في طريقة الدور |
| الغياب | **حسب الإعدادات**: إعادة حجز تلقائي بعد X يوم + رسالة، أو رسالة "افتقدناك" بس، أو ولا حاجة. مع مهلة سماح |
| ملف المريض | عام: شكوى، فحص، تشخيص، علامات حيوية، **حساسية**، أمراض مزمنة، مرفقات + **حقول إضافية** العيادة بتعرّفها من الإعدادات |
| تعرّف المريض | بالرقم أو الاسم أو رقم الملف. **الرقم مش unique** (عيلة على نفس الرقم) |
| الحسابات | بسيطة: نوع الزيارة وسعرها، الإعادة مجانية خلال X يوم، تسجيل الدفع، تقرير يومي |
| الروشتة | مكتوبة أو بالصوت، قوالب محفوظة، "كرر آخر روشتة"، تحذير حساسية. PDF مقاس A5 (أو A4). الطباعة: **تصميم كامل أو ورق العيادة المطبوع حسب الإعدادات**. النسخة المبعوتة دايمًا تصميم كامل |
| إرسال الروشتة | **اختياري من الإعدادات**: يتبعت تلقائي أول ما الكشف يخلص |
| الإملاء الصوتي | **Web Speech API من Chrome/Edge (مجاني)** + مطابقة تقريبية مع كتالوج الأدوية + مراجعة الدكتور إجبارية. الكود مجهز لـWhisper بعدين |
| الاستضافة | **لسه متحددتش**. التطوير local بـ`run.bat`، والقرار مطلوب قبل Phase 10 بس (الاختيارين موصوفين في 07) |
| التطوير | Windows من غير Docker (زي البرق). **بورتات ومجلدات مختلفة عن البرق** عشان الاتنين يشتغلوا على نفس الجهاز |
| التوقيت | التخزين UTC، العرض والحساب `Africa/Cairo` (بالتوقيت الصيفي) |

## الـWorkflow الأساسي

```
مكالمة → السكرتيرة تكتب الرقم/الاسم → (موجود؟ كارت المريض : إضافة سريعة)
      → تختار نوع الزيارة → المواعيد الفاضية → حجز → رسالة تأكيد تلقائية
      → تذكير قبلها بـ24 ساعة → تذكير قبلها بساعة
يوم الكشف: وصل (check-in + وزن/ضغط) → الدكتور يستدعيه → ملف المريض + الزيارة + الروشتة
      → إنهاء الكشف → طباعة الروشتة + (إرسالها لو مفعّل) → تسجيل الدفع → (حجز إعادة)
ما جاش: مهلة السماح → "لم يحضر" → حسب الإعدادات: إعادة حجز تلقائي + رسالة / رسالة "افتقدناك"
```
