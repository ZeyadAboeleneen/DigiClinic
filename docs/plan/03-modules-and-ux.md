# 03 — Screens & UX

مبادئ عامة: عربي RTL · كل شاشة يومية **تشتغل بالكيبورد** · HTMX partials (زي builder البرق) · toasts للأخطاء ·
الأرقام في الواجهة لاتيني · كل شاشة تتجرب على 1366×768 (لابتوب العيادة) و375px (موبايل الدكتور).

## 3.1 Sidebar حسب الدور
| الدور | الشاشات |
|---|---|
| reception | الاستقبال (الرئيسية) · حجز جديد · المرضى · المواعيد (تقويم) · الرسايل · الخزنة |
| doctor | شاشة الدكتور (الرئيسية) · المرضى · المواعيد · قوالب الروشتات · الأدوية · التقارير |
| admin/owner | كل اللي فوق + الإعدادات + المستخدمين + سجل النشاط |

## 3.2 شاشة الحجز (أهم شاشة للسكرتيرة) — هدف: **حجز مريض قديم في أقل من 20 ثانية، ومريض جديد في أقل من 45**

```
┌ بحث: [ 0100... أو اسم أو رقم ملف ]   (focus تلقائي، النتايج وهي بتكتب، ↑↓ Enter)
│
├ لو لقى → كارت المريض:
│   محمد أحمد · 34 سنة · ملف #1042 · 0100 123 4567 (واتساب ✓)
│   آخر زيارة: 2 سبتمبر (كشف) · عدد الزيارات 5 · ⚠ غاب مرتين
│   حجوزات جاية: الثلاثاء 14 أكتوبر 4:20 [تعديل] [إلغاء]
│   [فيه أكتر من مريض على نفس الرقم → تظهر كلهم كـcards: "محمد (34)"، "ياسين ابنه (6)"]
│
├ لو ملقاش → "مريض جديد" (form inline، نفس اللي اتكتب في البحث بيتملى تلقائي):
│   الاسم* · الموبايل* · ☑ نفس رقم الواتساب · الإيميل · السن أو تاريخ الميلاد · النوع · ☑ موافق على رسايل التذكير
│   → تحذير تكرار: "فيه مريض اسمه قريب على نفس الرقم: محمد أحمد علي #1042 — ده هو؟"
│
├ نوع الزيارة: [كشف 300] [إعادة — مجانية ✓ آخر كشف من 6 أيام] [استشارة]
│
├ المواعيد الفاضية:
│   slots: أعمدة أيام (14 يوم، ← →) وتحت كل يوم chips المواعيد. الأيام المقفولة رمادي بالسبب ("إجازة")
│   queue: كل يوم/فترة: "الثلاثاء — الفترة المسائية: رقم 8 · حوالي 3:45 · متبقي 12"
│
└ [تأكيد الحجز]  → ملخص + معاينة رسالة التأكيد اللي هتتبعت + الرسايل المجدولة (تأكيد الآن · تذكير الاثنين 4:20 م · تذكير الثلاثاء 3:20 م)
```
- اختصارات: `/` بحث · `N` مريض جديد · `Enter` تأكيد.
- بعد الحجز: toast + "حجز تاني لنفس المريض؟" + الشاشة ترجع للبحث فاضية.

## 3.3 التقويم (المواعيد)
عرض يوم/أسبوع. كل حجز بلون نوع الزيارة وأيقونة الحالة. سحب حجز لميعاد تاني = تأجيل (بتأكيد + رسالة).
الأيام المقفولة والاستثناءات واضحة. زرار "قفل يوم" بيفتح شاشة الحجوزات المتأثرة (12 §5).

## 3.4 شاشة الاستقبال (اليوم)

```
┌ النهارده الثلاثاء 14 أكتوبر · د. سارة · الفترة المسائية 2:00–9:00
│ [محجوز 18] [وصل 4] [عند الدكتور 1] [تم 6] [لم يحضر 1]        [+ حجز فوري (walk-in)]
├─────────────────────────────────────────────────────────────────────
│ 3:00 / #5 │ محمد أحمد │ كشف │ ● وصل 2:52 (مستني 8 دقايق) │ 300 ✓ مدفوع │ [دخّل] [⋯]
│ 3:20 / #6 │ منى سعيد  │ إعادة│ ○ محجوز · ✓✓ اتقرا التذكير │ 0           │ [وصل] [⋯]
│ 3:40 / #7 │ ...       │      │ ⚠ متأخر 12 دقيقة           │             │ [وصل] [لم يحضر]
│ ⋯ = تأجيل · إلغاء · تسجيل دفع · العلامات الحيوية · فتح الكارت · رجوع خطوة
└─────────────────────────────────────────────────────────────────────
```
- **[وصل]** → popup صغير اختياري: الوزن/الضغط/الحرارة (Tab بين الخانات، Enter حفظ) → `arrived`.
- **[دخّل]** (أو الدكتور يستدعي من عنده) → `in_consultation` → يظهر عند الدكتور.
- **[لم يحضر]** يدوي أو تلقائي بعد مهلة السماح → حسب السياسة (12 §7) + toast بالنتيجة ("اتحجزله الثلاثاء الجاي 3:40 واتبعتله").
- **الدفع**: [تسجيل دفع] → المبلغ المستحق متملي + طريقة الدفع. الإعادة المجانية مكتوب عليها "مجانية".
- Polling كل 5 ثواني (بيتغير بس لو فيه جديد). صوت تنبيه خفيف لما الدكتور يستدعي حد (اختياري).
- الترتيب: slots بالميعاد، queue برقم الدور، و"وصل" بيتعلم بلون.

## 3.5 شاشة الدكتور

```
┌ الطابور (عمود جانبي)                ┌ المريض الحالي ─────────────────────────────────
│ ▶ عندك: محمد أحمد (كشف)            │ محمد أحمد · 34 سنة · ذكر · ملف #1042 · الزيارة رقم 6
│ التالي: منى سعيد (إعادة) [استدعاء] │ 🔴 حساسية: Penicillin (شديدة)   🟠 مزمن: ضغط
│ منتظرين: 3 · لسه ماوصلوش: 9         │ آخر زيارة 2 سبتمبر: التهاب جيوب · روشتة RX-2026-00412
│                                     │ العلامات اليوم: 82 كجم · 130/85 · 37.2°
│ [إنهاء الكشف واستدعاء التالي]       ├ تبويبات: [الزيارة الحالية] [التاريخ] [الروشتات] [المرفقات] [البيانات]
│                                     │ الزيارة الحالية:
│                                     │  الشكوى 🎤 · الفحص 🎤 · التشخيص 🎤 (إكمال تلقائي من تشخيصاتك السابقة)
│                                     │  الخطة/ملاحظات 🎤 · حقول العيادة الإضافية · إعادة بعد [7] أيام
│                                     │  [الروشتة ←] (03 §3.6)
```
- **التاريخ**: timeline لكل الزيارات (التاريخ، التشخيص، الروشتة مختصرة، المرفقات) + فلتر + رسم بياني للوزن/الضغط لو فيه قيم.
- **المرفقات**: رفع بالسحب أو من الموبايل (كاميرا) + معاينة الصور والـPDF في نفس الصفحة.
- **[إنهاء الكشف]**: لو فيه روشتة draft → يطلب يأكدها الأول. بعدها: Visit finished → Appointment completed →
  (لو `send_prescription_after_visit`) الروشتة تتبعت → لو `followup_after_days` → إشعار للاستقبال "محتاج حجز إعادة يوم …"
  يظهر في شاشة الاستقبال كـtask.
- الدكتور يقدر يفتح أي مريض من البحث (مش لازم يكون في الطابور) لمراجعة الملف.
- Autosave لكل حقل (HTMX `hx-trigger="keyup changed delay:1s"`) — مفيش حاجة تضيع لو الصفحة اتقفلت.

## 3.6 شاشة الروشتة (Builder زي عرض السعر)

```
┌ الأدوية:  [ ابحث أو اكتب اسم الدوا… ] 🎤        [قوالب ▾] [كرر آخر روشتة]
│  1. Augmentin 1g — قرص         │ قرص كل 12 ساعة بعد الأكل │ لمدة 7 أيام │ ↕ ✕
│  2. Panadol Extra — قرص        │ عند اللزوم، بحد أقصى 4 يوميًا │          │ ↕ ✕
│  جمل جاهزة: [كل 8 ساعات] [كل 12 ساعة] [قبل الأكل] [بعد الأكل] [قبل النوم] [لمدة 5 أيام] …
│ ⚠ المريض عنده حساسية من Penicillin و Augmentin فيه Amoxicillin  ← تحذير لازم يتأكد بـcheckbox
│ نصايح: [ راحة وسوائل كتير ] 🎤     الزيارة الجاية: [21 أكتوبر]
│ [حفظ كقالب]  [معاينة]  [اعتماد وطباعة 🖨]  (+ "وابعتها للمريض" لو الإعداد مفعّل)
```
- دوا مش في الكتالوج → يتكتب حر + "ضيفه للكتالوج".
- الإكمال التلقائي مترتب بـ`usage_count` بتاع الدكتور ده.
- **تحذيرات**: حساسية (مطابقة الاسم التجاري + العلمي + aliases مع `Allergy.name`) · نفس الدوا مرتين.
- الاعتماد: `final` + رقم + PDF + نافذة طباعة. التعديل بعدها = "نسخة معدلة" `-R1`.

## 3.7 المرضى
- قائمة + بحث (الاسم/الرقم/رقم الملف) + فلاتر (آخر زيارة، عنده حجز، غياب كتير).
- صفحة المريض: البيانات · الحجوزات (جاية وقديمة) · الزيارات (للدكتور بس) · الرسايل · المدفوعات.
- **دمج مريضين مكررين** (admin/doctor): بيختار الأصلي، كل الحجوزات والزيارات والمرفقات بتتنقل، والمكرر `merged_into`.
- `import_patients <xlsx>` لو العيادة عندها شيت قديم (أعمدة: الاسم، الموبايل، السن، النوع، ملاحظات).

## 3.8 الإعدادات (admin/owner) — تبويبات
1. **العيادة**: الاسم، اللوجو، الألوان، الأرقام، العنوان، لينك الخريطة، سطر المواعيد.
2. **الدكتور والمواعيد**: بيانات الدكتور (للروشتة) · طريقة الحجز (ميعاد/دور) · جدول الأسبوع (لكل يوم: فترات بـ+، من/إلى، الطاقة) ·
   الاستثناءات (تقويم: قفل يوم/مواعيد مختلفة/يوم إضافي) · مدة الحجز قدام · أقل وقت قبل الحجز · "دورك قرّب" عند N.
3. **أنواع الزيارات**: الاسم، المدة، السعر، إعادة؟، مجانية خلال كام يوم، اللون.
4. **الرسايل**: تشغيل عام · ساعات الهدوء · القناة الافتراضية · fallback للإيميل · القوالب (لكل قالب: تشغيل، التوقيت، القناة، النص بمحرر فيه
   أزرار المتغيرات، Preview حي، "ابعت تجربة") · [+ تذكير إضافي].
5. **الغياب**: السياسة · مهلة السماح · إعادة الحجز بعد كام يوم · نطاق البحث.
6. **الروشتة**: المقاس A5/A4 · وضع الطباعة (تصميم كامل / ورق مطبوع) · هوامش الورق المطبوع بالمللي + **صفحة معايرة** ·
   إرسال الروشتة بعد الكشف (مقفول افتراضيًا) + القناة · الإملاء الصوتي (تشغيل/إيقاف).
7. **ملف المريض**: الحقول الإضافية (المريض/الزيارة) · مين يشوف العلامات الحيوية.
8. **الواتساب والإيميل**: زي البرق (QR، الحالة، SMTP، إيميل تجربة).
9. **المستخدمين**: زي البرق بالأدوار الجديدة.

## 3.9 الرئيسية / التقارير
- **السكرتيرة**: النهارده (أرقام الحالات) + مهام: "إعادات محتاجة حجز" · "رسايل فشلت" · "الواتساب مفصول" · "محرك الرسايل واقف".
- **الدكتور/owner**: زيارات اليوم/الشهر · مرضى جدد · نسبة الغياب · الإيراد (حسب طريقة الدفع) · أكتر تشخيصات · نسبة وصول التذكيرات وقرايتها.
- **تقرير الخزنة اليومي**: كل المدفوعات بالطريقة والمستلم + الإجمالي، قابل للطباعة.
