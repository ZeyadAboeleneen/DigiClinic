# 09 — Decisions & Open Questions

## محسوم (أكتوبر 2026)
| السؤال | القرار |
|---|---|
| نبني من الصفر ولا على البرق؟ | على البرق (fork) |
| طريقة الحجز | الاتنين حسب الإعدادات (slots / queue) لكل دكتور |
| حجم أول نسخة | دكتور واحد في الواجهة، والداتا جاهزة لأكتر |
| الغياب | حسب الإعدادات (إعادة حجز تلقائي / رسالة / ولا حاجة) + مهلة سماح |
| الإملاء الصوتي | Web Speech API من Chrome (مجاني) + مطابقة + مراجعة إجبارية |
| ملف المريض | عام + حقول إضافية بتتعرّف من الإعدادات |
| الحسابات | بسيطة (سعر لكل نوع زيارة، إعادة مجانية خلال X يوم، دفع، تقرير يومي) |
| ورق الروشتة | الاتنين حسب الإعدادات (تصميم كامل / مطبوع مسبقًا بمعايرة)، والمبعوت دايمًا كامل |
| إرسال الروشتة | اختياري من الإعدادات، مقفول افتراضيًا |
| Background jobs | `run_scheduler` بس (من غير Celery/Redis) |
| الـrealtime | HTMX polling |
