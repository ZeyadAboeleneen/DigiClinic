# 13 — Voice Dictation (الإملاء الصوتي)

## 13.1 القرار
**Web Speech API** من المتصفح (`webkitSpeechRecognition`) — مجاني، من غير أي سيرفر.
| الميزة | القيد |
|---|---|
| مجاني ومفيش إعداد | **Chrome وEdge بس** (Firefox/Safari لأ → زرار المايك ميظهرش + رسالة) |
| سريع ونتيجة لحظية | محتاج **HTTPS** (أو `127.0.0.1`/`localhost` في التطوير) |
| | محتاج **إنترنت**، والصوت بيعدي على سيرفرات جوجل → مذكور في سياسة الخصوصية + إعداد لإيقافه |
| | دقته ضعيفة في أسماء الأدوية الإنجليزي وسط كلام عربي → المطابقة (13.3) |

## 13.2 الواجهة
- زرار 🎤 جنب كل حقل نصي في الزيارة (الشكوى، الفحص، التشخيص، الملاحظات، النصايح) وفي الروشتة.
- ضغطة = بدء (المايك أحمر + موجة) · ضغطة تانية أو سكوت 3 ثواني = إيقاف. اختصار `Ctrl+Space`.
- `lang` = `ar-EG` افتراضيًا، مع زرار تبديل سريع `en-US` (الدكتور بيملي اسم دوا لوحده).
- النتيجة المؤقتة (interim) بتظهر رمادي، والنهائية بتتضاف للحقل **عند مكان المؤشر** (مش بتمسح المكتوب).
- أوامر بسيطة: "سطر جديد" → `\n`، "نقطة" → `.`.
- ملف واحد `static/src/dictation.js` (Alpine component) بواجهة provider:
  ```js
  // DictationProvider: start(lang), stop(), onInterim(cb), onFinal(cb), onError(cb), isSupported()
  // WebSpeechProvider (v1) · WhisperProvider (مستقبلًا: MediaRecorder → upload → /api/transcribe/)
  ```

## 13.3 إملاء الروشتة + مطابقة الأدوية
1. الدكتور يدوس 🎤 في الروشتة ويقول: "اوجمنتين واحد جرام قرص كل اتناشر ساعة بعد الأكل لمدة اسبوع، بنادول اكسترا عند اللزوم".
2. النص بيتقسم لسطور (فاصل: "،" / "سطر جديد" / وقفة طويلة).
3. لكل سطر `POST /prescriptions/match/` → الـserver:
   - `normalize_ar` + تحويل الأرقام المكتوبة ("واحد"→1، "اتناشر"→12) لجزء الجرعة.
   - مطابقة أول كلمتين/تلاتة مع `Drug.name` + `generic_name` + **`aliases_ar`** بـ`rapidfuzz` (`WRatio`, threshold 80)،
     وترتيب بـ`usage_count`.
   - مطابقة باقي السطر مع `DosePhrase` (اختياري) لتنظيف التعليمات.
4. الواجهة بتعرض لكل سطر: **أفضل 3 اقتراحات** للدوا + التعليمات المستخرجة → الدكتور يختار بضغطة أو يعدل.
5. أول ما الدكتور يختار دوا لنص معين لأول مرة ("اوجمنتين") → **يتضاف تلقائيًا لـ`aliases_ar`** بتاع الدوا ده
   → النظام بيتعلم نطق الدكتور مع الوقت.

## 13.4 الأمان (إجباري)
- **مفيش حاجة من الإملاء بتتحفظ أو تتطبع من غير ما الدكتور يشوفها**: السطور الجاية من الصوت بتظهر بعلامة "من الصوت — راجع"
  لحد ما الدكتور يأكدها، وزرار [اعتماد] مقفول طول ما فيه سطر مش متأكد.
- تحذيرات الحساسية والتكرار بتشتغل على السطور دي زي المكتوبة بالظبط.

## 13.5 Tests
- Python: المطابقة (اوجمنتين → Augmentin 1g، بنادول اكسترا → Panadol Extra، "فلاجيل" → Flagyl، كلمة مش موجودة → مفيش اقتراح فوق 80)،
  تحويل الأرقام المكتوبة، التعلم من الاختيار.
- JS: `isSupported()` false → الزرار مخفي. (اختبار الصوت نفسه يدوي.)
